# 小说书架维护

书架入口为 `/book`，每本书使用固定的 `/books/<id>` 地址。正式章节连续编号；从章内拆出的小剧场、番外和感言挂在所属章节下，默认折叠，不占正文章号。点击章节标题进入正文，点击右侧小箭头展开 / 收起附篇，不另设「阅读」按钮。正文结束后的番外集中在目录末尾的单独「番外」分支中，各篇按原文顺序排列。搜索子条目或正在阅读子条目时自动展开对应分支；倒序只调整父条目顺序，子条目仍按原文顺序阅读。

所有正文与附篇仍保留独立阅读位置，上一章 / 下一章按原文顺序衔接。`?chapter=N` 是含附篇的内部条目序号（从 1 开始），不等同于显示的正文章号；目录中的编号跳转使用正文章号。章内附篇的阅读页提供所属章节链接，书末番外显示篇目位置。正文内容不补写，原始标题与源文件位置保存在目录数据中用于核对和进度迁移。无章节参数时继续当前浏览器的上次阅读。

## 数据与导入

- `src/books/overrides.json`：人工维护的稳定 ID、分类、简介、别名、作者补充及封面路径、出处。`match` 对应文件名中的原始主书名，`title` 可覆盖展示书名，旧书名可保留为 `alias`；`id` 应保持稳定，避免已有链接与进度失效。
- `scripts/book-parser.mjs`：识别带空格、中文数字或阿拉伯数字的章标题，保留段落与原始顺序，清理空白、导出用等号分隔线和非法控制字符，再按明确标题拆出番外、感言，建立所属章节和书末番外标记；只给正式章节生成显示编号。
- `scripts/import-books.mjs`：生成书目、导入核对报告和静态正文；开发与发布均不再依赖本机的 Book 目录。
- `public/books/<id>/<revision>-index.json`：按原文顺序排列的阅读条目、所属章节 `parentChapter`、书末番外标记 `appendix`、内容类型、显示标题、原文标题、源章节和段落位置、旧版本迁移表、段落数量与原文前言。书架详情和阅读器的「简介」标签展示原文 `简介:` 之后的完整段落；原文没有简介时使用书目摘要。书架卡片展示简短摘要。
- `public/books/<id>/<revision>-N.json`：每批最多 24 节的正文数组。扁平条目保持原文顺序，树形目录只改变展示层级。内容版本进入文件名，避免更新后读到旧缓存；旧版本不会自动删除，清理前应核对发布缓存与旧客户端需求。

新增小说先在 `overrides.json` 中登记，只有书名的 TXT 需要在配置中补充作者。导入支持多个目录或单独文件；只收录配置中的书，未登记文件打印提示并保留原样。当前导入命令：

```bash
node scripts/import-books.mjs /home/zxabinbina/桌面/Book /home/zxabinbina/下载/隐藏在霍格沃茨当教授.txt
node scripts/check-books.mjs
npm run build
```

导入后检查 `import-report.json`，只对人工配置和代码运行格式化；生成的正文无需格式化。部署完整 `dist/` 即可，包括 `books/*.html`、目录、正文分块和本地封面，不需要新增后端。

书架提供完整简介对话框、搜索、状态筛选、排序和卡片 / 列表视图。已读状态指当前访客读到所收录文本的结尾，并不表示作品已经完结。阅读器收起全站导航，保留已播放的音乐；简介、目录、书签、全文搜索和设置独立展开。专注模式自动请求浏览器全屏；退出按钮在鼠标靠近右上角时显示，离开约 650ms 后淡出，首次进入和触屏轻点正文时保留 1.8 秒提示。键盘聚焦时始终可见，Escape 或浏览器退出全屏时返回普通阅读。浏览器拒绝全屏时保持可用的专注布局并提示；离开阅读器会释放由阅读器进入的全屏。滚动模式的方向键切换章节；翻页模式的方向键、空格、Page Up / Down 或手机横向滑动切换书页，章末继续进入下一章。

全文搜索由 `src/books/content.ts` 实现，点击搜索后才读取正文，按字面匹配、不执行正则，最多显示 200 个匹配段落，可以取消。搜索结果和书签链接使用 `?chapter=N&paragraph=P&offset=R`，段落从 1 开始，段内比例范围 0–1。定位完成后移除临时段落参数，保留章节参数，刷新会继续最新阅读位置。

## 浏览器存储与验证

- `homepage-reading:<id>`：`progress.ts` 按书保存版本、章节序号、章标题、段落序号、段内比例、章节进度与更新时间。滚动后 180ms 保存，翻页、切章、离开页面、隐藏标签页或 `pagehide` 时立即保存。
- `homepage-bookmarks:<id>`：`bookmarks.ts` 保存每本书最多 500 个书签，包含位置、原文摘录和时间。支持跳转和删除；目录调整后通过迁移表恢复对应的章节和段落。
- `homepage-reader-settings`：`readerSettings.ts` 保存阅读方式、纸张、字体、字号、行距、段距与宽度。兼容旧版 `homepage-reader-font-size`，提供恢复默认按钮。

正文尚未加载、加载失败或旧请求完成时不会覆盖进度。损坏的存储数据忽略，禁止存储时显示提示；目录整理版本通过源章节与段落映射迁移旧进度和书签，包括原先藏在正文里的番外位置，以及曾单独分组或连续编号的番外和附记；树形目录版本保留全部条目与段落位置；无已知映射的版本才保留有效章节并重置段落。浏览器前进 / 后退在章节加载后恢复该历史条目的原滚动位置或分页段落；标签页内最多保留 256 个历史位置；普通进入或刷新按本地记录恢复。分页重排恢复到包含目标段落片段的书页，因此不同屏幕可能从该段更早的位置显示。记录不会上传，不跨设备同步，清除站点数据后会丢失。

阅读器只渲染当前章节，内存最多缓存两批正文；章节请求 15 秒、全文搜索 45 秒未完成时提示失败，支持重试；切换页面取消请求并忽略过期结果。正文与搜索结果通过 Vue 文本插值显示，TXT 内的 HTML 不执行。首次打开和加载尚未缓存的正文需要网络，未实现整站离线阅读。
