# 军旗界面说明

军旗路径为 `/games/junqi`。页面与交互在 `src/games/JunqiGame.vue`，规则、随机布阵与交换校验在 `src/games/junqi.ts`，暗棋观察、推断与电脑决策在 `src/games/junqiKnowledge.ts`，样式位于 `src/style.css` 的 `.junqi-*` 范围；具体参数见 [DESIGN.md](../DESIGN.md#军旗)。

## 本次核对的行为

棋盘图形与规则共用铁路节点和跨山通路，三处桥梁连接两方。工兵、炸弹分别登记，避免工兵被标为炸弹；同级和炸弹碰撞后双方移除，攻击失败只移除攻击者。行营内棋子免受攻击，但可出去攻击；棋子进入大本营后不能移动。对方无合法行棋时结算，避免电脑停在无棋可走的状态。

布阵不保存到浏览器。开始前可交换两枚己方棋子，军旗限大本营、地雷限后两排、炸弹不能在最前排。悔棋恢复玩家行棋前的局面与记录，同时取消电脑计时与装饰动画；重开或离开页面清理未完成任务。电脑采用本地启发式选择，适合休闲练习。

## 明棋练习与暗棋挑战

默认「练习 · 明棋」保持双方身份可见，原有电脑策略继续使用。「挑战 · 暗棋」隐藏电脑军衔，保留棋盘、位置和移动；点击未知棋子可标记，也可打开「标记与推测」后点选任意棋子。选中我方棋子时，侧栏显示电脑的推测，窗口列出候选军衔。判断可能有误，不代表真实军衔或专业棋力。

按本次要求，双方的推测相互公开：玩家标记同步给电脑，电脑会将其作为玩家对自身棋子的看法，用于隐蔽身份和行动取舍；玩家也能查看电脑对自己的判断。标记不作为已确认身份，不向电脑提供玩家的真实隐藏军衔。司令阵亡时公布这一事件并亮出该方军旗，结束时揭示剩余棋子。

裁判使用真实局面判定合法行棋与吃子。挑战电脑仅接收 `JObservation`：自身军衔、对方位置与候选军衔、公开移动、吃子结果和已亮军旗；未知军衔为 `null`。初始候选来自合法布阵约束，移动排除军旗与地雷，铁路转弯可确认工兵，吃子结果结合观察者自身军衔缩小候选，并结合标准棋子数量排除不可能身份。决策按候选评估收益和风险，不直接读取对方隐藏属性；明棋策略与暗棋策略使用不同输入。

敌方棋面、可访问名称、标记窗口、移动飞行层和最近记录均遮蔽未确认身份。推测文字与已确认身份分开。标记按棋子 ID 跟随移动，被吃后清除；整轮悔棋恢复对应局面、标记、候选与亮旗状态。切换模式或重开清理计时、动画及旧标记，重开保留模式；离开或刷新不保存对局。标记与推测窗口在网页全屏上方使用独立模态层，关闭后恢复站位焦点，Escape 先关闭窗口。
